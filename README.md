# OctopusBridge

Перевод и модификация игр на ПК. Поддерживаются **RPG Maker MV/MZ**, **Ren'Py**, **Twine** и **TyranoScript**.

Текст переводится двумя способами: **в реальном времени** прямо в игре и **пакетно** — по файлам.

Версия: **0.5.0** · [English](README.en.md)

## Возможности

- **Пакетный перевод** — извлечение текста из игры, перевод, внедрение обратно, экспорт/импорт CSV. При повторном извлечении старые переводы восстанавливаются.
- **Живой перевод** — текст в игре переводится на лету; перевод можно выключить и включить в любой момент, не останавливая игру.
- **Читы и инструменты** — зависят от движка: переменные, золото, карты, редактор сейвов, просмотр ресурсов, патч шрифта.
- **Провайдеры перевода** — Honyaku (офлайн, NLLB), Google Free, Bing, чередование Google+Bing, OpenAI-совместимый API.
- **Глоссарий и память переводов** — общая база на все проекты (SQLite), маскирование игровых кодов (`\C[8]`, `<center>` и т. п.).
- **Единый кэш переводов** — все движки пишут один файл `octopus_cache.json` в папке игры; старые кэши читаются и переносятся автоматически.
- **Удобный интерфейс** — тёмная тема, русский/английский, системный трей, drag-and-drop игр, «О программе» и «Что нового».

## Движки

| Движок | Статус | Транспорт |
|---|---|---|
| RPG Maker MV / MZ | стабильно | CDP (Chromium/NW.js) |
| Ren'Py | стабильно | Frida + Python-агент в процессе |
| Twine (SugarCube) | экспериментально | HTTP + WebSocket мост |
| TyranoScript / TyranoBuilder | поддерживается | CDP (NW.js) |

## Требования

- Windows 10/11 (64-бит).
- ~500 МБ на диске + офлайн-модели Honyaku (по желанию, от ~60 МБ на пару языков).
- Ren'Py требует Frida-инъекции — антивирус может запросить подтверждение.

## Установка

1. Скачайте установщик `OctopusBridge-0.5.0-Setup.exe` из релизов и запустите.
2. При первом запуске приложение предложит скачать офлайн-переводчик (можно пропустить — останутся Google/Bing/AI).

> EXE не подписан — Windows SmartScreen может показать предупреждение («Подробнее → Выполнить в любом случае»).

## Быстрый старт

1. **Откройте игру** — перетащите папку игры или `Game.exe` в окно приложения (или в список на вкладке «Проекты»).
2. **Файлы** — вкладка «Файлы»: извлеките текст, переведите, внедрите обратно.
3. **Реалтайм** — запустите игру через приложение: текст в игре начнёт переводиться сам.
4. **Читы / карты / сейвы** — появляются во вкладках движка после открытия проекта.

## Примечания

- Google/Bing — неофициальные бесплатные endpoints: без ключей, но могут быть ограничены по объёму. Для больших проектов используйте офлайн Honyaku или AI.
- Инъекции изменяют процесс игры в памяти — используйте инструмент только на играх, которые вам принадлежат или которые вам разрешено модифицировать.
