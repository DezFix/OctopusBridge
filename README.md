# OctopusBridge

Перевод и модификация игр на ПК: **RPG Maker MV/MZ**, **Ren'Py**, **Twine** и **TyranoScript**.

Текст переводится в реальном времени прямо в игре или пакетно — по файлам.

[English version](README.en.md)

## Возможности

- **Пакетный перевод** — извлечение текста из игры, перевод, внедрение обратно, экспорт/импорт CSV.
- **Живой перевод** — текст в игре переводится на лету, можно включить/выключить без остановки игры.
- **Читы и инструменты** — зависят от движка: переменные, золото, карты, редактор сейвов, просмотр ресурсов.
- **Провайдеры перевода** — Argos Translate (офлайн), Google Free, Bing, чередование Google+Bing, OpenAI-совместимый API.
- **Глоссарий и память переводов** — общая база (SQLite), маскирование игровых кодов (`\C[8]`, `<center>` и т. п.).
- **Интерфейс** — русский/английский, тёмная тема, системный трей, автозапуск.

## Движки

| Движок | Статус | Технология |
|---|---|---|
| RPG Maker MV / MZ | стабильно | CDP (Chromium/NW.js) |
| Ren'Py | стабильно | Frida + Python-агент |
| Twine (SugarCube) | экспериментально | HTTP + WebSocket |
| TyranoScript / TyranoBuilder | стабильно | CDP (NW.js) |

## Требования

- Windows 10/11 (64-бит).
- ~500 МБ диска плюс офлайн-пакеты Argos (по желанию, 100–300 МБ каждый).

## Установка

1. Скачайте установщик из релизов и запустите его.
2. При первом запуске приложение предложит скачать офлайн-переводчик (можно пропустить — останутся Google/Bing/AI).

> EXE не подписан — SmartScreen может показать предупреждение («Подробнее → Выполнить в любом случае»).

## Быстрый старт

1. **Откройте игру** — перетащите папку игры или `Game.exe` в окно приложения.
2. **Файлы** — извлеките текст, переведите, внедрите обратно.
3. **Реалтайм** — запустите игру через приложение: текст начнёт переводиться сам.

## Сборка и тесты из исходников

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python run_tests.py   :: тесты
build.bat                            :: exe в dist\
build.bat --installer                :: + установщик Inno Setup
```

Сборкой управляет `build_app.py` (`python build_app.py --help`), версия берётся из `app/__init__.py`.

## Примечания

- Google/Bing — неофициальные бесплатные endpoints: без ключей, но могут быть ограничены по объёму.
- Инъекции изменяют процесс игры в памяти — используйте только на играх, которые вам принадлежат или которые вам разрешено модифицировать.
- Меняйте местами переводы и следите за изменениями версий в [CHANGELOG.md](CHANGELOG.md).
